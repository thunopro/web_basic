# Rùa Toán Basic report

The report source follows the supplied FDA report class. Main chapters are in `chapters/`; the generated PDF is `Rua_Toan_Basic_Report.pdf`.

Compile from this folder with:

```sh
latexmk -xelatex -interaction=nonstopmode -jobname=Rua_Toan_Basic_Report main.tex
```

Before submission, fill in the course code, class, group, student names/IDs, contribution percentages, and repository URL. The deployed demo is `https://ruatoanbasic.vercel.app`.
