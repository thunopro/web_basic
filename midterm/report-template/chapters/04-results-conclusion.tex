\subsection{What the implementation achieves}
Rùa Toán Basic delivers the complete core learning loop on a transparent, lightweight stack:
3,381 collections and 33,929 problems, 90 lessons, 216 books and resources, and 89 documents
are browsable, filterable, and paginated, with mathematical notation rendered by MathJax.
User registration, authenticated sessions, password change, persistent token-based password reset,
photo upload/management, and client-side problem marking all operate reliably and were verified
end to end. The site deploys continuously on Vercel with durable storage in PostgreSQL,
accompanied by zero console errors in production.

\subsection{Limitations and risks}\label{sec:limits}
\begin{enumerate}[label=L\arabic*.]
  \item \textbf{Catalogue validation.} Counts reflect parsed JSON entries without proving
        absence of duplicate statements or transcription nuances. Ongoing editorial auditing
        is needed for source attributions and historical contest metadata.
  \item \textbf{Runtime search scalability.} Full-text queries scan an in-memory normalised
        list (approx. 16 MB of JSON). While instantaneous for current traffic, larger catalogues
        would benefit from a PostgreSQL full-text search index (\texttt{tsvector}).
  \item \textbf{Photo storage model.} Photos are stored as binary data in PostgreSQL. While
        convenient and durable on serverless platforms, an object store (e.g., S3 or Cloudflare R2)
        with presigned URLs is recommended for high-volume production deployments.
  \item \textbf{Email delivery for resets.} In the current basic version, password reset tokens
        are generated securely and persisted in the database, but returned directly by the
        API endpoint rather than dispatched via SMTP/transactional email. Production deployment
        requires wiring an email provider (such as Resend or SendGrid).
  \item \textbf{Automated CI pipeline.} Although a comprehensive automated smoke test script
        (\texttt{smoke\_test.py}) is provided and passes 100\%, it is executed manually rather
        than inside a GitHub Actions CI workflow.
\end{enumerate}

\subsection{Lessons learned and future work}
Developing Rùa Toán Basic demonstrated the value of architectural transparency: eliminating
framework overhead made network calls, database queries, and DOM rendering immediately inspectable
and debuggable. Unifying the design system with CSS custom properties enabled dark mode and
responsive presentation without CSS bloat or runtime penalties.

Key future extensions include:
\begin{itemize}
  \item Integrating an automated GitHub Actions CI workflow to run \texttt{smoke\_test.py} on every push.
  \item Connecting a transactional email service for automated password reset dispatch.
  \item Migrating binary photo storage to an S3-compatible blob store.
  \item Adding interactive practice quizzes with immediate feedback.
\end{itemize}

\subsection{Conclusion}
Rùa Toán Basic accomplishes its educational and architectural objectives. The learning platform
operates on a stack that any student or evaluator can inspect end to end: plain HTML pages,
clean JavaScript interactions, and a lightweight FastAPI backend connected to PostgreSQL.
By resolving routing anomalies, hardening security headers, persisting account recovery,
unifying visual styling, and verifying zero console errors in production, the application
provides a robust foundation for secondary school mathematics practice.
