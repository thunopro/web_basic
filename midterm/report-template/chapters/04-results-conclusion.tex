\subsection{What the implementation achieves}
Rùa Toán Basic achieves its complete educational and functional loop:
3,381 collections and 33,929 problems, 90 lessons, 216 books, and 89 documents are seamlessly
browsable, filterable, and paginated, with mathematical notation dynamically typeset by MathJax.
User registration, authenticated cookie sessions, credential updating, single-use password resets,
homework photo management, and client-side problem bookmarking all operate reliably. The entire site
deploys continuously on Vercel with zero console errors, zero build complexity, and durable PostgreSQL persistence.

\subsection{Limitations and risks}\label{sec:limits}
\begin{enumerate}[label=L\arabic*.]
  \item \textbf{Catalogue validation.} Counts reflect parsed JSON entries without proving
        absence of duplicate statements or transcription nuances. Ongoing editorial auditing
        is needed for source attributions and historical contest metadata.
  \item \textbf{Runtime search scalability.} Full-text queries scan an in-memory normalised
        list (approx. 16 MB of JSON). While instantaneous for current traffic, larger catalogues
        would benefit from a PostgreSQL full-text search index (\texttt{tsvector}).
  \item \textbf{Photo storage model.} Photos are stored as binary data in PostgreSQL. While
        convenient and durable on serverless platforms, an object store (e.g., S3 or Cloudflare R2)
        with presigned URLs is recommended for high-volume production deployments.
  \item \textbf{Email delivery for resets.} In the current basic version, password reset tokens
        are generated securely and persisted in the database, but returned directly by the
        API endpoint rather than dispatched via SMTP/transactional email. Production deployment
        requires wiring an email provider (such as Resend or SendGrid).
  \item \textbf{Automated CI pipeline.} Although a comprehensive automated smoke test script
        (\texttt{smoke\_test.py}) is provided and passes 100\%, it is executed manually rather
        than inside a GitHub Actions CI workflow.
\end{enumerate}

\subsection{Lessons learned and future work}
Developing Rùa Toán Basic was an essential, transformative educational milestone for our entire team.
Pivoting from the overly complex, framework-heavy Next.js architecture to a plain HTML/CSS/JS and
FastAPI foundation allowed the group to genuinely understand the foundational mechanics of web systems.
Instead of relying on automated framework abstractions and opaque bundlers, the team learned how to
construct resilient HTTP endpoints, design intuitive user interfaces using CSS custom properties,
safely handle binary file uploads with magic byte verification, and maintain stateless session cookies securely.

The collective code walkthroughs and collaborative bug-fixing sessions proved invaluable. Every team
member developed a concrete appreciation for cross-browser differences, asynchronous request lifecycles,
and database connection management under serverless concurrency.

Key future extensions include:
\begin{itemize}
  \item Integrating an automated GitHub Actions CI workflow to run \texttt{smoke\_test.py} on every push.
  \item Connecting a transactional email service for automated password reset dispatch.
  \item Migrating binary photo storage to an S3-compatible blob store.
  \item Adding interactive practice quizzes with immediate feedback.
\end{itemize}

\subsection{Conclusion}
Rùa Toán Basic accomplishes its educational and architectural objectives with honesty and rigor.
Rather than presenting a complex black-box application whose inner workings remain obscure, this project
showcases an application that the group has conceived, debugged, and understood from the ground up.
By combining lightweight technologies with exhaustive validation (26/26 automated smoke tests passed,
near-perfect Lighthouse scores, and zero console errors in production), Rùa Toán Basic demonstrates that
mastering foundational web technologies provides the strongest possible bedrock for future software engineering.
